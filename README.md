# 🚀 IDEALAUNCH

### Discover Ideas. Build the Future.

IDEALAUNCH is a modern frontend web application designed to help users discover, explore, save, and manage innovative startup ideas.

The project provides a simple and interactive platform where users can browse different startup ideas, search and filter ideas by category, view detailed information, and save their favourite ideas.

---

## 🌟 Features

### 🔐 User Authentication
- User Sign Up and Login
- Email and password validation
- User registration using localStorage
- Session management using sessionStorage
- Protected pages
- Logout functionality
- User-specific sessions

### 🏠 Dashboard
- Personalized dashboard
- Overview of startup ideas
- Quick access to different sections
- Modern futuristic interface

### 🔎 Explore Ideas
- Browse startup ideas
- Search ideas by keywords
- Filter ideas by category
- View idea cards with important information

### 💾 Saved Ideas
- Save favourite startup ideas
- Remove saved ideas
- User-specific saved ideas
- Saved ideas remain available during future visits

### 📄 Idea Details
- View complete information about an idea
- Idea description
- Category
- Problem and solution
- Target audience
- Other relevant information

### 👤 User Profile
- Display logged-in user's information
- Manage user session
- Logout option

### 📱 Responsive Design
- Works across desktop, tablet, and mobile screen sizes
- Responsive layouts
- User-friendly interface

---

## 🎨 Design

IDEALAUNCH uses a **Dark Futuristic UI** with:

- Dark background
- Neon-inspired accents
- Gradient elements
- Glass-like cards
- Smooth animations
- Modern typography
- Responsive components

The design focuses on creating a futuristic environment for discovering and exploring startup ideas.
